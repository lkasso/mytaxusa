---
name: prior-year-variance
description: Compare this year's return with last year's and decide which differences need an explanation. Use whenever prior.json is not null.
---
If prior.json is null, skip this and say so in one line.

Flag, in order of importance:
1. Dependents added or removed. Always needs an explanation.
2. Filing status changed.
3. Total wages or income changed by more than 10 percent. Check whether the documents explain it (a partial-year W-2, unemployment income). Either way, ask the taxpayer to confirm, and put the explanation you found in the question's reason. A variance over the threshold is never a pass.
4. Employer added or removed, address changed.

For each unexplained change, write a client question: what changed, what you saw in each year, and what you need to know. Do not guess a reason.
